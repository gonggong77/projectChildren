- [x] 공연 상세(`/pblprfr/{mt20id}`)를 적재하고, 예매처·소개 이미지를 자식 테이블에 저장한다
- [x] `prfage`를 파싱해 `prfage_min_norm`에만 저장한다 (필터에는 미사용)
- [x] 공연시설 상세(`/prfplc/{mt10id}`)를 적재하고 좌표·편의시설·무장애 필드를 저장한다
- [x] 놀이시설 전국 전량을 페이지 단위로 적재한다
- [x] 놀이시설 좌표를 D2 순서(API → CSV 병합 → 지오코딩)로 확보하고, 좌표 없는 시설은 제외한다

- [x] 배치 실행 결과를 `ingest_logs`에 기록한다
- [x] 자동 스케줄은 사용자 요구로 제외하고 수동 적재 방식으로 운영한다 (D5 예외)
- [x] 배치를 1회 수동 실행해 SQLite에 데이터가 쌓이는지 확인한다 (AC-11)

### 3. 서버 API — 공통 · 지역 · 목록

- [x] `GET /api/health`에 상태와 최종 적재 시각을 포함한다
- [x] CORS 허용 오리진을 화이트리스트로 제한한다
- [x] 오류 응답 포맷 `{"code","message"}`와 목록 공통 필드(`total`,`page`,`size`)를 통일한다
- [x] `GET /api/regions` — 시도·구군 행정표준코드 목록을 반환한다
- [x] `GET /api/performances` — 키워드(`q`)·기간·정렬·페이징으로 공연 목록을 조회한다 (M1 백엔드)
- [x] `GET /api/performances`에 시도(`sido`)·구군(`gugun`) 필터를 추가한다 (M2 백엔드)

### 4. 서버 API — 상세 · 배치 · 인근 놀이시설

- [x] `GET /api/performances/{mt20id}` — 공연 + 공연장 병합 상세를 반환한다 (PRD 4절 노출 필드, snake_case)
